## 지금 위치

- 완성도: **1단계** — 내 컴퓨터에서만 돈다. DB, Ollama, 백엔드, AI 서버, USB 연결, 앱을 손으로 차례로 켜야 한다.
- 목표 단계: ③에서 정한다.
- 끝나는 날: 2026-12-31 목표. 늦어지면 주간 점검에서 범위를 줄이거나, 이유를 적고 날짜를 옮긴다.

완성도 6단계: 1 내 컴퓨터에서 돈다 → 2 남이 받아서 돌린다(README, docker compose, `.env.example`) → 3 배포 → 4 실제 사용자가 쓰고 의견을 받아 고침 → 5 혼자 굴러간다(CI, 오류 기록, 백업, 다시 배포하는 방법) → 6 제품(인증, 개인정보, 법적 검토, 확장)

## ① 끝난 모습

완료했을 때의 README 첫 화면. 숫자는 지어내지 않고, 측정한 뒤에 채운다.

```text
PnN
영양제 성분표와 먹는 약 정보를 비교해서 설명서의 상호작용 문장을 근거로 안전한지 알려주는 안드로이드 앱

- 써 보기: (설치 링크)
- 실제 사용: ___명이 자기 약·영양제로 사용 (성분표 사진 ___장)
- 사용자 의견: ___건 중 ___건 반영 (예: ___)
- 사진 인식: 실사용 사진 ___장, 성분 ___개 중 ___개 인식
- 상호작용 판단: 시험 문장 ___개 중 ___개 정답
- 응답 시간: 사진 1장 ___초, 검사 1건 ___초
- 자동 테스트 ___개, 코드를 올릴 때마다 자동 실행
```

빈칸을 채우려면 필요한 것:

| 빈칸 | 필요한 것 |
|---|---|
| 써 보기 | 배포된 서버, 설치 파일(APK) |
| 실제 사용 | 지인 사용 기간, 서버의 사용 횟수 기록 |
| 사용자 의견 | 의견 받는 양식 |
| 사진 인식 | 지인 사진을 시험용으로 남길 동의, 저장소 안의 채점 스크립트 |
| 상호작용 판단 | 시험 문장 세트와 채점 스크립트를 저장소에 |
| 응답 시간 | 서버가 걸린 시간을 기록 |
| 자동 테스트 | CI 설정 |
